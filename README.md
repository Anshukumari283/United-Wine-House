# United 🍷

United is a modern wine shop production web application designed to showcase premium wines, streamline product presentation, and provide customers with an elegant browsing experience.

## ✨ Features
- **Clean UI/UX**: Simple, intuitive design for wine lovers.
- **Product Showcase**: Highlight wines with descriptions, images, and categories.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile.
- **Scalable Structure**: Easy to extend with new products or features.

## 📂 Project Structure
- `index.html` → Main landing page
- `assets/` → Images, icons, and media files
- `css/` → Stylesheets for layout and design
- `js/` → Scripts for interactivity
